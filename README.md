## Deployment

This portfolio website can be published using Github Pages.

### Github Pages Setup

1. Open the repository on GitHub.
2. Navigate to **Settings**.
3. Select **Pages** from the sidebar.
4. Under **Buil and deyloyment**, select **Deploy from a branch**.
5. Select the `main` branch.
6. Choose `/(root)` as the folder.
7. Click **Save**.

Once deployment is complete, the website will be accessible through its GitHub Pages URL.
